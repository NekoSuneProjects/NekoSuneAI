Game Agent (VRChat)
Stopped
NekoSuneAI plays autonomously over VRChat's official OSC and narrates its thoughts in chat (and on voice). Enable OSC in VRChat's Action Menu — see .env for setup.
VRChat Friends (opt-in)
Off
Auto-accepts friend requests, watches friend online/offline via VRChat's unofficial web API, and sends a thank-you chatbox message. Needs credentials in Settings → VRChat Friends — this is against VRChat's ToS for bots, so use a throwaway account, not your main.
Set VRChat username/password (and TOTP secret if 2FA) in Settings → VRChat Friends, and enable it there, before starting.
👁️ Watch & React (screen)
Off
