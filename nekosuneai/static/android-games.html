Android Gameplay

Control approved Android game agents on your network. Commands are queued to the paired device. This preview does not yet show live video or autonomous AI actions.

Autonomous Android gameplay (experimental)

Requires the Android worker to be started with a trusted Ollama endpoint and explicit game.autoplay.start approval. Main queues the goal; the existing Android runtime makes decisions using the configured model.

Manual game input

Only input to the selected, running game is allowed. Tap coordinates are Android screenshot pixels, not Windows desktop pixels.
