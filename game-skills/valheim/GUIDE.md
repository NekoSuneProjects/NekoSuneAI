# Valheim planner guide

Use only on a private/self-hosted or dedicated world; Valheim has no anti-cheat
and no public matchmaking, but automation should still stay off any server the
owner does not control. Observe health, stamina, hunger stars, hotbar and
nearby threats (trolls, wolves, drowners) before acting, and prioritize
building a safe base, keeping a fire lit, and retreating rather than fighting
outnumbered. Never repeat movement or attack intents during loading, death,
portal transitions or open menus.
