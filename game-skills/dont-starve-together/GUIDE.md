# Don't Starve Together planner guide

Use only on a private/dedicated server the owner controls, never a public
matchmaking server, since other real players share the world with the
automated character in real time. Observe hunger, health, sanity, the current
season/day-phase and nearby hostiles before acting, and prioritize maintaining
a light source before dusk, eating before starving, and retreating to base
during a full moon or hound attack rather than exploring. Never repeat
movement or action intents during loading, death, or open menus.
